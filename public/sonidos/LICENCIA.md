# Sonidos de Entre Hojas

Efectos de sonido generados para este proyecto con ElevenLabs (Sound Effects, modelo
`eleven_text_to_sound_v2`) desde la cuenta del proyecto, con plan de pago. Su uso se rige por los
términos de servicio de ElevenLabs para contenido generado. No son grabaciones de terceros.

| Archivo | Qué es |
| --- | --- |
| `roce-nuevo-1.mp3`, `roce-nuevo-2.mp3` | roce continuo de papel nuevo (se usa en bucle) |
| `roce-antiguo-1.mp3`, `roce-antiguo-2.mp3` | roce continuo de papel viejo y seco (en bucle) |
| `golpe-nuevo-1..3.mp3` | la hoja nueva se asienta |
| `golpe-antiguo-1..3.mp3` | la hoja antigua se asienta |
